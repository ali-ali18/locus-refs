# Categorias

Categorias são tags reutilizáveis que podem ser associadas a recursos dentro de um workspace.


## `GET /api/categories`

Retorna todas as categorias do workspace autenticado.

### Resposta `200`

```typescript
{
  id: string;
  name: string;
  slug: string;
  userId: string;
  workspaceId: string;
  _count: { resources: number };
}[]
```


## `POST /api/categories`
