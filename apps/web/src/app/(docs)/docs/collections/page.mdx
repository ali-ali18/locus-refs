# Coleções

Coleções organizam recursos ou notas em grupos temáticos dentro do workspace. O campo `isNoteCollection` distingue coleções de notas de coleções de recursos.


## `GET /api/collection`

Retorna todas as coleções do workspace.

### Resposta `200`

```typescript
{
  id: string;
  name: string;
  slug: string;
  description: string | null;
  color: string | null;
  isNoteCollection: boolean;
  userId: string;
  workspaceId: string;
}[]
```


## `POST /api/collection`

Cria uma nova coleção.

### Corpo da requisição

<DocsTable>
  <thead>
    <tr><th>Campo</th><th>Tipo</th><th>Descrição</th></tr>
  </thead>
  <tbody>
    <tr><td><code>name*</code></td><td><code>string</code></td><td>Nome da coleção</td></tr>
    <tr><td><code>description</code></td><td><code>string</code></td><td>Descrição</td></tr>
    <tr><td><code>color</code></td><td><code>string</code></td><td>Identificador de cor</td></tr>
    <tr><td><code>isNoteCollection</code></td><td><code>boolean</code></td><td>Define se é coleção de notas (padrão: <code>false</code>)</td></tr>
  </tbody>
</DocsTable>

### Resposta `201`

```typescript
{
  message: "Collection created successfully";
  collection: {
    id: string;
    name: string;
    slug: string;
    description: string | null;
    color: string | null;
    isNoteCollection: boolean;
    userId: string;
    workspaceId: string;
  };
}
```

## `DELETE /api/collection/[id]`

Remove uma coleção.

### Resposta `200`

```typescript
{ message: "Collection deleted successfully" }
```
