# Motivos

O Refstash nasceu de uma necessidade real: ter uma base de código moderna, bem estruturada e pronta para ser adaptada — sem precisar começar do zero toda vez.

## A história

O ponto de partida foi bem mais simples do que o projeto é hoje: um sistema de notas bruto que recebia apenas texto puro — nada de formatação, nada de imagens, só um campo de TXT. Era o suficiente para o que precisávamos na época.

A partir daí surgiu a ideia de trabalhar junto com meu irmão. As atividades eram escolares — ele não tem nenhuma relação com programação, não sabia o que estava por trás da ferramenta e não precisava saber. A dinâmica era direta: ele fazia as atividades e eu fazia a revisão depois. Para isso precisávamos de um lugar para organizar referências, anotações e ideias de forma mais estruturada.

Conforme a necessidade foi crescendo, o projeto foi crescendo junto. O TXT virou um editor rich-text, apareceram as coleções, as categorias, o upload de imagens, a colaboração em tempo real. Cada funcionalidade entrou porque fez falta — não por planejamento antecipado.

Com o tempo, passamos a usar o projeto também em **treinamentos** — para organizar ideias, centralizar referências e manter o material acessível de forma estruturada.

## Mantido por uma pessoa

O projeto é desenvolvido e mantido por uma única pessoa, **nas horas vagas**. Isso significa que o ritmo de desenvolvimento é irregular por natureza — às vezes sai muito em pouco tempo, às vezes fica parado por semanas.

O foco atual está em **expandir as funcionalidades**. Há bugs conhecidos que serão corrigidos conforme o tempo permitir. Se você encontrar algo, sinta-se à vontade para abrir uma issue no [repositório](https://github.com/ali-ali18/locus-refs).

## 100% gratuito e open source

Não há planos pagos, limites de uso ou dependência de serviços proprietários. O código é aberto, o deploy é seu, os dados são seus. Você tem controle total sobre o que roda e onde roda.

O projeto usa tecnologias que você já provavelmente conhece — Next.js, Prisma, PostgreSQL, Tailwind — sem abstrações desnecessárias que dificultam o entendimento ou a adaptação.

## Servidor de teste disponível

Um servidor público está disponível para quem quiser explorar a aplicação sem configurar nada localmente. Você pode criar uma conta, testar os fluxos e avaliar se faz sentido para o seu caso.

> **Atenção:** O servidor de teste é **limpo semanalmente**. Não use para dados que precise manter — ele existe apenas para avaliação.

## A ideia central

A proposta é simples: **dar uma base sólida para quem precisa**.

Para quem só quer se organizar, o projeto funciona direto — crie uma conta, monte suas coleções, escreva suas notas e guarde suas referências.

Para quem quer ir além, o código está aberto para:

- Estudar como uma aplicação full-stack moderna é estruturada
- Entender como funciona autenticação baseada em workspace
- Adaptar o projeto para um caso de uso próprio
- Usar como ponto de partida para algo maior

O Refstash não tenta ser um produto final para todos — ele tenta ser um ponto de partida honesto, com código legível, boas práticas e documentação clara o suficiente para que qualquer pessoa consiga colocar em produção ou modificar conforme precisa.
