# Workspace

Operações de gerenciamento do workspace. Ações destrutivas exigem o papel de **owner**.


## `DELETE /api/workspace`

Remove o workspace do usuário autenticado. Exige que o usuário seja o **owner** do workspace.

**Efeitos colaterais:**
- Apaga toda a organização e seus dados no banco
- Remove a logo do S3 (se existir)

### Resposta `200`

```typescript
{ message: "Workspace deletado com sucesso" }
```
