# Introdução

O **Refstash** é uma plataforma de gerenciamento de notas e coleções de recursos. Esta documentação cobre a API REST interna que alimenta a aplicação.

A API segue convenções REST padrão — todas as respostas são JSON, os status HTTP refletem o resultado da operação, e o acesso é protegido por sessão autenticada.

## Conceitos fundamentais

### Workspace

Toda operação ocorre dentro de um **workspace**. Um usuário pode pertencer a múltiplos workspaces, mas cada requisição opera no contexto de um workspace ativo. O servidor resolve esse contexto automaticamente a partir da sessão — você não precisa passar o workspace ID na maioria das rotas.

### Sessão

A autenticação é baseada em sessão via [Better Auth](https://www.better-auth.com/). Após o login, a sessão é persistida em cookie e enviada automaticamente em todas as requisições. Não há tokens Bearer — a sessão é o mecanismo de autenticação.

### Recursos

Os principais recursos da API são:

- **Categorias** — tags reutilizáveis associadas a recursos
- **Coleções** — grupos temáticos para organizar notas ou recursos
- **Notas** — documentos rich-text editados com Tiptap
- **Recursos** — links externos com metadados (título, descrição, imagem OG)

## Respostas

### Sucesso

```json
{
  "message": "Descrição da operação",
  "data": { }
}
```

### Erro

```json
{
  "error": "Mensagem amigável ao usuário",
  "code": "ERROR_CODE"
}
```
